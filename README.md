# mBot2 3Dシミュレーター

mBlock と同じブロックを組み立てて、mBot2 の動きを 3D で確認するページです。

- 公開ページ: https://ne23-1258d.github.io/mbot2-3d-sim/ (ID での保存・呼び出しは使えません)
- 画面: `mbot2-3d-sim.html` (1ファイルで動きます。ライブラリは CDN から読み込みます)
- 保存サーバー: `server.py` (Python 3 の標準ライブラリだけ。データは SQLite)

## ID で保存・呼び出し (ログイン不要)

```
python server.py
```

ブラウザで http://127.0.0.1:8080/ を開きます。

1. 画面の「ID で保存・呼び出し」で「保存して ID をもらう」を押すと、**6桁の ID** が出ます。
2. あとで同じ画面を開き、「6桁の ID」に入力して「呼び出す」を押すと、保存したプログラム (ブロックとスタート位置) が戻ります。
3. 同じブラウザで保存した ID は、画面に一覧で残ります (そのブラウザの中だけに記録します)。

データは `programs.db` に入ります (git には入れません)。

| 設定 | 例 |
|---|---|
| 校内の他のパソコンからも使う | `python server.py --host 0.0.0.0 --port 8080` |
| データの置き場所を変える | `python server.py --db /var/lib/mbot2/programs.db` |
| 保存しておく日数 (既定 180 日。0 で消さない) | `python server.py --keep-days 365` |

### 管理 (別のターミナルで実行できます)
| | |
|---|---|
| 件数を見る | `python server.py --admin-count` |
| ID を指定して削除 | `python server.py --admin-delete 123456` |

### API
| | |
|---|---|
| `POST /api/programs` | 保存 `{"xml":"<xml…","startPose":"line"}` → `{"code":"123456"}` |
| `GET /api/programs/<6桁の ID>` | 呼び出し → `{"code","xml","start_pose","created_at"}` |
| `GET /api/ping` | つながっているかの確認 |

### 注意
- ログインはありません。**ID を知っている人は、誰でも読み込めます。** 他の人に見せたくない内容は保存しないでください。一覧の表示と、他の人による上書き・削除はできません。
- 6桁の ID を当てずっぽうで探されないよう、同じ接続元から1分間に15回まちがえると、1分間止めます。保存も、10分間に20回までです。メモリの中だけで数えるので、サーバーを止めると忘れます。
- 校内で使う場合は、学校のネットワークの中だけにとどめてください。インターネットに公開する場合は、前に別のサーバー (nginx など) を置く、ログインを足す、などの対策をしてください。
- 保存するのはブロックの XML だけです。実機に書き込む機能は、まだありません。

## mBlock に持っていく
画面の「mBlock 用に書き出す (.sb3)」で保存したファイルを、mBlock の「ファイル → コンピューターから開く」で開きます。
