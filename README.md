# mBot2 3Dシミュレーター

mBlock と同じブロックを組み立てて、mBot2 の動きを 3D で確認するページです。
コースは 2m × 2m、mBot2 は実物に近い大きさで動きます。

- 公開ページ: https://ne23-1258d.github.io/mbot2-3d-sim/
- 画面: `mbot2-3d-sim.html` (1ファイルで動きます。ライブラリは CDN から読み込むので、インターネットが必要です)
- 保存サーバー: `server.py` (Python 3 の標準ライブラリだけ。データは SQLite)

## できること

- mBlock と同じ見た目・名前・初期値のブロック (mBot2 シャーシ / クアッドRGBセンサー / イベント / 制御 / 演算 / 変数) を組み立てて、動かす
- サンプル「線をたどる」「色マスを順に踏む」(緑 → 青 → 赤 → 黄の順に踏む課題)
- 手動操作 (矢印キー)、視点の切り替え (斜め / 追従 / 真上)
- **mBlock 用に書き出す (.sb3)**: mBlock の「ファイル → コンピューターから開く」で開くと、同じブロックが mBot2 のデバイスに並びます
- **ID で保存・呼び出し** (ログイン不要): 要 `server.py`

## 保存サーバー (ID で保存・呼び出し)

```
python server.py
```

ブラウザで http://127.0.0.1:8080/ を開きます (このアドレスだけを入力してください)。

1. 「ID で保存・呼び出し」の「保存して ID をもらう」で、**6桁の ID** が出ます。
2. あとで同じ画面を開き、「6桁の ID」を入力して「呼び出す」を押すと、ブロックとスタート位置が戻ります。
3. 同じブラウザで保存した ID は、画面に一覧で残ります (そのブラウザの中だけの記録です)。

### 起動のオプション

| 目的 | コマンド |
|---|---|
| このパソコンの中だけで使う (既定) | `python server.py` |
| 公開ページ (github.io) からも使う | `python server.py --allow-origin https://ne23-1258d.github.io` |
| 同じネットワークの他のパソコンからも使う | `python server.py --host 0.0.0.0` |
| ポートを変える | `python server.py --port 9000` |
| データの置き場所を変える | `python server.py --db /var/lib/mbot2/programs.db` |
| 保存しておく日数 (既定 180 日。0 で消さない) | `python server.py --keep-days 365` |

オプションは、組み合わせて指定できます。

### 公開ページから、このパソコンのサーバーを使う

1. `python server.py --allow-origin https://ne23-1258d.github.io` で起動します。
2. **Chrome か Edge** で、公開ページを開きます。
3. 「ID で保存・呼び出し」に「サーバーにつながっています」と出れば成功です。つながらないときは、「サーバーのアドレス」の欄に `http://127.0.0.1:8080` と入れて、「つなぐ」を押します。
4. ブラウザが「ローカル ネットワークへの接続を許可しますか」と聞いてきたら、許可してください。

> Safari では、つながらない可能性が高いです。確実に試すなら、`http://127.0.0.1:8080/` を直接開いてください。

### 他のパソコンから使う

- **同じルーター (同じネットワーク) の中**: `python server.py --host 0.0.0.0` で起動し、他のパソコンのブラウザで `http://(このパソコンの IP アドレス):8080/` を開きます (IP アドレスは `ipconfig` で調べます)。Windows ファイアウォールで、プライベート ネットワークの通信を許可してください。
- **別のルーター (別のネットワーク)**: `192.168.x.x` のアドレスは、そのままでは通じません。Tailscale などの VPN で同じネットワークに入れるか、一時的にインターネットへ公開する方法を使います。
- 公開ページ (https) から、他のパソコンの `http://192.168…` へは、ブラウザの安全の決まりでつなげません。他のパソコンでは、サーバーのアドレスを、直接開いてください。

### 管理 (別のターミナルで実行できます)

| | |
|---|---|
| 件数を見る | `python server.py --admin-count` |
| ID を指定して削除 | `python server.py --admin-delete 123456` |

## データベースと ID

- データベースは **SQLite** です。`server.py` と同じフォルダの `programs.db` というファイル1つに、保存されます (git には入れません)。
- `saved` という表に、`code` (ID)、`xml` (ブロックのデータ)、`start_pose` (スタート位置)、`created_at` (保存日時) が入ります。
- ID は、100000〜999999 のランダムな 6 桁です。`code` は主キーで、**同じ ID は重なりません** (重なったときは、自動で作り直します)。
- SQL への入力は、すべてプレースホルダで渡しています。

## API

| | |
|---|---|
| `POST /api/programs` | 保存 `{"xml":"<xml…","startPose":"line"}` → `{"code":"123456"}` |
| `GET /api/programs/<6桁の ID>` | 呼び出し → `{"code","xml","start_pose","created_at"}` |
| `GET /api/ping` | つながっているかの確認 |

## 安全面の注意

- ログインはありません。**ID を知っている人は、誰でも読み込めます。** 他の人に見せたくない内容は保存しないでください。一覧の表示と、他の人による上書き・削除はできません。
- 6桁の ID を当てずっぽうで探されないよう、同じ接続元から 1 分間に 15 回まちがえると、1 分間止めます。保存も、10 分間に 20 回までです。回数はメモリの中だけで数えます (サーバーを止めると忘れます)。
- 1回の保存は 300KB まで、保存できる件数は 20,000 件までです。
- 別のサイトからの書き込みは、`--allow-origin` で許可したサイト以外は断ります。
- 校内で使う場合は、学校のネットワークの中だけにとどめてください。インターネットに公開する場合は、前に別のサーバー (nginx など) を置く、ログインを足す、などの対策をしてください。

## 動作の前提と限界

- 動力 100% は 160 rpm、車輪は滑らない、という前提です。実機では、床の材質や電池の残りで動きが変わります。
- ブロックの見た目・名前・初期値・メニューは、mBlock の画面から取り込んでいます。音・LED・見た目・AI など、動きに関係しないブロックは省いています。
- 「CyberPiが起動したとき」「ボタンAが押されたとき」の2つは、mBlock への書き出しが、未確認です。
- クアッドRGBセンサーの状態値 (0〜15) のビットの並びと、偏差の符号は、実機の説明で確認できていません。
- 実機の mBot2 への書き込みは、まだできません。
